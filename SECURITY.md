# Security policy

The `main` branch is the supported version of this pilot project.

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/alexkoukos/voiceagent/security/advisories). Include reproduction steps and the affected code path when possible. Do not post credentials, call recordings, transcripts, or customer information in a public issue.

If a credential may have been exposed, revoke or rotate it with its provider immediately.
