06 / ΣΥΧΝΕΣ ΕΡΩΤΗΣΕΙΣ

Όσα θέλετε να ξέρετε, πριν μιλήσουμε.

Αν η επιχείρησή σας έχει ιδιαίτερο τρόπο λειτουργίας, θα τον συζητήσουμε στο προσωπικό demo.

Κρατάω τον σημερινό μου αριθμό;

Ναι. Ο στόχος είναι να συνεχίσετε να χρησιμοποιείτε τον δημόσιο αριθμό σας. Η προώθηση και οι διαθέσιμες επιλογές ελέγχονται με βάση τον πάροχο ή το τηλεφωνικό σας σύστημα.

Μπορεί να απαντά πρώτα η γραμματεία μου;

Ναι. Η προτεινόμενη αρχική ρύθμιση είναι να απαντά πρώτα η ομάδα σας και ο βοηθός να καλύπτει τις κλήσεις που δεν προλαβαίνετε.

Απαντά εκτός ωραρίου;

Μπορεί να ρυθμιστεί ώστε να αναλαμβάνει εκτός ωραρίου, εφόσον το τηλεφωνικό σας σύστημα υποστηρίζει την αντίστοιχη προώθηση.

Μιλά ελληνικά και αγγλικά;

Η βασική εμπειρία είναι στα ελληνικά. Η δυνατότητα αγγλικών ελέγχεται στο δικό σας demo πριν ενεργοποιηθεί για πελάτες.

Με ποιο ημερολόγιο συνεργάζεται;

Υποστηρίζεται σύνδεση με Google Calendar. Αν χρησιμοποιείτε άλλη πλατφόρμα κρατήσεων, θα ελέγξουμε μαζί τον τρόπο που μπορεί να ενταχθεί στη ροή σας.

Τι γίνεται αν δεν μπορεί να βοηθήσει;

Ακολουθεί τη διαδικασία μεταφοράς ή επανάκλησης που θα έχουμε συμφωνήσει και μπορεί να κρατήσει μήνυμα για την ομάδα σας.

Χρειάζεται οι πελάτες μου να εγκαταστήσουν εφαρμογή;

Όχι. Οι πελάτες καλούν τον συνηθισμένο αριθμό της επιχείρησής σας.

Πώς χειρίζεται κλήσεις και προσωπικά στοιχεία;

Κατά τη ρύθμιση συμφωνούμε τις πληροφορίες που χρειάζεται να συλλέγει, τις ειδοποιήσεις και τη διατήρηση δεδομένων. Για ιατρεία, ο βοηθός αναλαμβάνει διοικητικά αιτήματα και δεν δίνει ιατρικές συμβουλές.
